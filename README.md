# 星途平台 - 学业科研仪表盘

> 前端课程设计作品 · 纯HTML/CSS/JS实现

## 📋 项目简介

**星途平台**是一个面向大学生的学业科研管理仪表盘，整合了任务管理、课程学习、竞赛团队、资源库、社区交流等功能模块，帮助学生一站式管理学业与科研生活。

项目采用**纯前端实现**，基于 Tailwind CSS + Font Awesome + 原生 JavaScript 构建，页面交互丰富，响应式布局适配多端。

## ✨ 核心功能

### 1. 仪表盘首页
- 📊 4大核心指标统计卡片（学习时长、任务数、竞赛数、资源数）
- 📅 周日程表可视化
- 📋 待办任务列表
- 🏆 竞赛进度追踪

### 2. 任务管理
- ✅ 全部任务总览
- 📝 任务详情页
- ⏰ 学习时长统计
- 🎯 计划管理

### 3. 课程学习
- 📚 多门课程展示（Python、数据结构、HTML/CSS等）
- 📖 课程详情与进度
- 🏁 课程完成统计

### 4. 竞赛团队
- 🏆 竞赛信息展示
- 👥 团队成员管理
- 📋 项目报告
- 📅 团队会议记录

### 5. 资源社区
- 📚 资源库分享
- 💬 社区交流
- ✉️ 消息通知
- 📝 经验分享

### 6. 个人中心
- 👤 个人设置
- 🔔 通知管理
- 🎨 界面定制

## 🛠️ 技术栈

| 类别 | 技术 |
|------|------|
| **HTML** | HTML5 语义化标签 |
| **CSS** | Tailwind CSS 3.x + 自定义样式 |
| **JavaScript** | 原生 JS（ES6+）、localStorage 本地存储 |
| **图标** | Font Awesome 6.x |
| **CDN** | BootCDN 国内加速 |

## 🚀 快速开始

直接用浏览器打开 `index.html` 即可浏览。

> 注：部分页面有登录拦截，可在 login.html 输入任意账号密码登录（前端演示用）。
